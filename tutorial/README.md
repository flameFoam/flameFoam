Overview
========
+ Tutorial case for a simple flame acceleration tube with annular obstacles
+ The main purpose of this tutorial is to demonstrate the case setup for
  premixed turbulent flame RAS modeling using the ETFC combustion model with
  Zimont turbulent burning velocity correlation and Malet laminar burning
  velocity correlation

Output
======
+ Temperature and pressure field values are probed at several locations
+ Progress c variable profile is sampled along the tube
